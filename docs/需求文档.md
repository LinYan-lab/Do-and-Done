# 需求文档（已确认版本）

最后更新：2026-08-21

## 1. 窗口形态

- 桌面角落有一个小悬浮按钮。
- 点击小悬浮按钮 → 展开为“滚动日历”（展示某一段时间内的日期）。
- 滚动日历上再点展开按钮 → 展开为完整月历（展示一个月所有日期）。
- 滚动日历也可以保持常驻在桌面上。
- 悬浮窗口应尽量不遮挡其他应用程序。

## 2. 两种模式

- **ToDo List 模式**：按天添加待办，支持横跨多日的大目标。
- **纪念日模式**：展示普通节假日 + 用户自定义纪念日（如生日），支持按农历添加。

## 3. 日期染色规则（已修正确认）

按完成率 x 给日期上色：

| 完成率 | 颜色 |
| --- | --- |
| x = 100% | 蓝色 |
| 60% ≤ x < 100% | 绿色 |
| 20% ≤ x < 60% | 黄色 |
| 0% ≤ x < 20% | 红色 |

染色规则：

- 只对“添加了待办项目的当天及过去日期”染色。
- 未来日期不染色。
- 没有待办项目的日期不染色。
- 颜色在日历的所有形态（悬浮按钮、滚动日历、完整月历）和所有模式（ToDo、纪念日）中同步显示。

## 4. 界面语言

- 默认中文。
- 后续再支持其他语言（本轮不做，也不预留字段）。

## 5. 数据设计原则
