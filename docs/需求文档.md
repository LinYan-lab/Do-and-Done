# 需求文档（已确认版本）

最后更新：2026-08-21

## 1. 窗口形态

- 桌面角落有一个小悬浮按钮（手绘便签样式），可拖动，位置自动记忆；
- 点击悬浮按钮 → 展开为“滚动日历条”（展示一段连续日期，支持滚轮、按住拖动、
  按钮翻页，可无限滚动）；
- 滚动日历条上再点“展开月历” → 展开为完整月历（一个月所有日期）；
- 滚动日历条也可以保持常驻在桌面上；面板右上角 ✕ 可收起；
- 悬浮按钮尽量不遮挡其他应用程序（默认小面积置顶，可拖到角落）。

## 2. 两种模式

- **ToDo List 模式**（默认）：按天添加待办，支持横跨多日的大目标；
- **纪念日模式**：标题栏按钮一键切换；只展示普通节假日 + 用户自定义纪念日
  （如生日），纪念日支持按农历添加，每年重复；
- 点击日期时，按当前模式分别进入“任务页”或“纪念日页”。

## 3. 任务与完成率口径

- 跨多日任务会在它覆盖的每一天出现，可以逐日勾选进度；
- **完成率只统计“结束日期 = 当天”的任务**：跨多日任务只算它的最后一天，
  中间的天数只是展示进度，不影响当天完成率（2026-08-21 确认）；
- 任务页顶部统计文字为“今日到期：已完成 x/y”。

## 4. 日期染色规则（已修正确认）

按完成率 x 给日期上色：

| 完成率 | 颜色 |
| --- | --- |
| x = 100% | 蓝色 |
| 60% ≤ x < 100% | 绿色 |
| 20% ≤ x < 60% | 黄色 |
| 0% ≤ x < 20% | 红色 |

染色规则：

- 只对“添加了待办项目的当天及过去日期”染色；
- 未来日期不染色；
- 没有待办项目的日期不染色；
- 颜色在日历的所有形态（滚动日历条、完整月历）和所有模式（ToDo、纪念日）中同步显示；
- 黄色底自动使用深色文字，保证对比度。

## 5. 纪念日

- 内置节假日：元旦、劳动节、国庆节、春节、元宵节、清明节、端午节、中秋节、重阳节；
- 自定义纪念日：支持公历 / 农历，每年重复；
- 纪念日模式下，格子显示名称：自定义纪念日优先，其次内置节日；
- 已知限制：调休上班日暂未包含；闰月农历暂不支持；暂无一次性纪念日。

## 6. 界面语言与风格

- 默认中文，后续再支持其他语言（本轮不做，也不预留字段）；
- 界面风格：手绘涂鸦（Hand-Drawn Sketch），详见 [UI风格.md](UI风格.md)。

## 7. 数据设计原则

- 不为未来功能预留数据库字段，后续需要时再添加。
