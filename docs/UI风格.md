# UI 风格说明：手绘涂鸦（Hand-Drawn Sketch）

最后更新：2026-08-21

## 设计定位

界面看起来像一页被认真整理过的笔记本：点阵纸背景、便签卡片、铅笔线条、
硬边投影，鼓励“先写下来再说”。所有组件依然遵循清晰的布局网格和信息层级，
只是视觉上刻意保留一点“手感”。

## 色板

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 纸白 | `#FBF9F2` | 背景、卡片 |
| 旧纸 | `#F4F1E6` | 次级背景 |
| 点阵 | `#E5E1D4` | 点阵纸网格 |
| 深蓝灰墨 | `#3B4252` | 正文、标题、描边 |
| 注释灰蓝 | `#6B7488` | 说明文字 |
| 铅笔灰 | `#8A93A6` | 细线、边框 |
| 便签黄 | `#FFF3C4` | 主按钮、任务卡片、悬浮便签 |
| 便签粉 | `#FDE2E4` | 纪念日卡片 |
| 便签蓝 | `#DCEEFB` | “今天”格子 |
| 便签绿 | `#DFF2D8` | 预留 |
| 硬阴影 | `#C9C3B4` | 硬边投影 |

完成率四色为语义色：天光蓝 `#6FA8C9`、叶绿 `#7FAF7B`、
暖琥珀 `#E2B568`、陶土红 `#C97B63`，黄色底自动用深色文字。

## 字体

- 全局优先使用楷体 `AR PL UKai CN`（系统无则回退到 Comic Relief / Noto Sans CJK）；
- 标题、按钮、日期数字用粗体；说明文字用灰蓝色小字。

## 主要组件

- **悬浮按钮**：淡黄便签，平时歪 2°，悬停转正并抬起，按下压回；
- **面板**：点阵纸背景 + 右上角铅笔 doodle（螺旋、波浪、小箭头）+ 抖动墨线外框；
- **日期格子**：自绘小纸片，硬阴影 + 抖动铅笔边；今天为浅蓝便签并带“今”；
  选中为加粗墨线；完成率颜色作为纸面底色；
- **任务 / 纪念日卡片**：淡黄 / 淡粉便签，虚线描边 + 硬投影；
- **按钮**：纸色底 + 墨色描边，悬停加粗边框、按下文字下沉；
- **输入框**：2px 铅笔灰边框，聚焦时加粗为 3px 墨色（用线条变化表达，而非强颜色）。

## 交互

- Hover：亮度微升 / 边框加粗 / 阴影变深变远（纸片“抬起”）；
- Active：轻微下沉、旋转反向、阴影收拢（“按回去”）；
- 目前为即时样式切换；300–500ms 弹性动画（悬停放大、旋转过渡）尚未实现。

## 实现说明

- 所有主题常量与公共样式集中在 `calendar_todo/ui/theme.py`，改配色只动一个文件；
- 点阵、doodle、抖动边框、硬阴影全部由 QPainter 代码绘制，不依赖图片资源；
- 抖动边框的随机种子由矩形坐标决定，重绘不会乱跳；
- 若要更精致的手绘插画或纸纹，可后续用图片资源替换或叠加。
