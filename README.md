# 日历 + ToDo List

一个运行在 Ubuntu 桌面上的日历与待办管理软件。
计划包含：悬浮日历窗口（可展开成月历）、ToDo List 完成率染色、纪念日（含农历）等功能。

## 运行方法

第一次运行前，先创建虚拟环境并安装依赖：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

以后每次运行都只用一条命令：

```bash
.venv/bin/python main.py
```
